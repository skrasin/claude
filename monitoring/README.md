# Мониторинг приказов о зачислении РЭУ

Почасовая проверка страницы приказов о зачислении РЭУ им. Г.В. Плеханова:
https://www.rea.ru/pk/entrant/bakalavriat-i-spetsialitet/prikazes

Отслеживается приказ о зачислении в Высшую школу менеджмента (бакалавриат),
внебюджет / платное обучение по договору.

## Файлы

- `rea-prikazes.md` — последний снимок содержимого страницы. Сравнение
  очередной выгрузки с этим файлом и есть детектор изменений.
- `rea-monitor-status.md` — журнал запусков: `OK` (страница получена),
  `CHANGED` (обнаружено изменение), `BLOCKED` (сеть не пустила),
  `NOTIFIED-BLOCKED` (о длительной блокировке сообщено один раз).

## Как это работает

Расписание живёт в Routine окружения `Claude` (cron `23 * * * *`, UTC).
Каждое срабатывание поднимает свежую сессию — это важно: сетевая политика
окружения применяется при создании контейнера, поэтому свежая сессия
работает с актуальным списком разрешённых доменов.

Пользователь получает уведомление только при реальном изменении страницы.
Молчаливый запуск — нормальный результат.
