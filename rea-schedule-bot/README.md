# Расписание РЭУ → Telegram (Synology)

Каждый вечер в 20:00 бот присылает расписание группы **15.26Д-ТЭ01/26б** на завтра:

```
Расписание на завтра, вторник 17.11, начало 8:30

8:30–10:00 Дизайн путешествий и блогинг
Лабораторная работа

10:10–11:40 Микроэкономика
Практическое занятие
```

Если пары поменялись с прошлой проверки — внизу будет блок «⚠️ Изменения».
Если сайт недоступен или формат страницы изменился — придёт предупреждение, а не тишина.

Нужен только Python 3, который уже есть в DSM 7. Ничего устанавливать не надо.

## Установка через веб-интерфейс DSM (без SSH)

### 1. Файлы
1. Откройте **File Station** и создайте папку, например `scripts/rea-schedule-bot`
   (полный путь будет вида `/volume1/scripts/rea-schedule-bot`. Точный путь видно
   в «Свойствах» папки).
2. Загрузите туда `schedule_bot.py`.
3. На своём компьютере откройте `config.example.json` в любом текстовом редакторе, вставьте
   токен от @BotFather вместо `ВСТАВЬТЕ_ТОКЕН_ОТ_BOTFATHER` (кавычки оставить), сохраните как
   **`config.json`** и загрузите в ту же папку.

### 2. Часовой пояс
**Панель управления → Региональные параметры** — должен стоять Москва (GMT+03:00).

### 3. Проверка связи с Telegram
**Панель управления → Планировщик задач → Создать → Запланированная задача → Пользовательский сценарий**
- Общие: имя `Расписание — проверка`, пользователь — ваш (не обязательно root).
- Расписание: любое (запускать будем вручную).
- Параметры задачи → Пользовательский сценарий:
  ```
  python3 /volume1/scripts/rea-schedule-bot/schedule_bot.py --ping
  ```
Сохраните, выделите задачу, нажмите **Выполнить**. В Telegram должно прийти «✅ Бот расписания на связи».

### 4. Пробный запуск с сайтом
Отредактируйте ту же задачу, замените сценарий на:
```
python3 /volume1/scripts/rea-schedule-bot/schedule_bot.py --dump
```
и снова **Выполнить**. Придёт либо расписание на завтра, либо предупреждение.
В папке появится `dump.html` — если что-то не так, скачайте его и пришлите для настройки.

### 5. Ежедневный запуск
Создайте вторую задачу (или переделайте первую):
- Расписание: **Ежедневно**, время **20:00**.
- Сценарий:
  ```
  python3 /volume1/scripts/rea-schedule-bot/schedule_bot.py
  ```
- По желанию в «Параметрах задачи» включите отправку результата на e-mail при ошибке.

## Режимы

| Команда | Что делает |
|---|---|
| *(без параметров)* | расписание на завтра → Telegram |
| `--ping` | пробное сообщение в Telegram |
| `--dry-run` | только напечатать сообщение, не отправлять |
| `--dump` | сохранить ответ сайта в `dump.html` |
| `--date 2026-11-21` | расписание на указанную дату |
| `--from-file dump.html` | разобрать сохранённую страницу вместо запроса к сайту |

## Файлы
- `schedule_bot.py` — скрипт.
- `config.json` — токен, chat_id, группа. **Не публикуйте**: токен даёт полный доступ к боту.
- `state.json` — создаётся сам, хранит прошлый снимок расписания для поиска изменений.
