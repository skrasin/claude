# skrasin/claude

Репозиторий разовых задач. Каждая разовая задача живёт в своей ветке и ни от
чего не зависит. В этой ветке — оглавление и одна постоянная вещь:
**[`telegram-bot/`](telegram-bot/)**, Telegram-бот на домашнем Synology NAS
(общая основа для всех его задач; контекст в
[`telegram-bot/BOT-CONTEXT.md`](telegram-bot/BOT-CONTEXT.md)).

Работа по лейблу FANCYMUSIC — релизы, рассылки, продюсирование мероприятий,
площадки, бюджеты, договоры — лежит в отдельном приватном репозитории
**skrasin/FANCYMUSICprivate**, сюда она не возвращается.

только в своей. Смотреть нужно ту папку, ради которой ветка заведена.

## Как добавить задачу

Новая ветка от этой, имя `claude/<про-что>-<суффикс>`, строка в таблицу выше.
Ветки друг в друга не вливаются: их незачем сводить в одно дерево.
