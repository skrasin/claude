# skrasin/claude

Репозиторий разовых задач. Общего кода нет: каждая задача живёт в своей
ветке и ни от чего не зависит. Эта ветка — только оглавление.

Работа по лейблу FANCYMUSIC — релизы, рассылки, продюсирование мероприятий,
площадки, бюджеты, договоры — лежит в отдельном приватном репозитории
**skrasin/FANCYMUSICprivate**, сюда она не возвращается.

## Что в каких ветках

| Ветка | Что это | Состояние |
|---|---|---|
| `claude/monitor-admission-orders-jkvoxq` | Мониторинг приказов о зачислении РЭУ им. Плеханова: почасовая проверка страницы, журнал запусков в `monitoring/` | Август 2026, расписание в Routine окружения |
| `claude/massage-survey-results-k5o4fm` | Опрос «Как прошёл массаж»: две страницы на GitHub Pages, ответы в Google-таблицу через Apps Script | Август 2026 |
| `claude/website-security-analysis-g7ersh` | Анализ безопасности сайта fstravel: разбор и HTML-отчёт | Август 2026 |
| `claude/kids-game-home-design-z07v0s` | «Дом мечты» — браузерный редактор дома и интерьера для подростков | Август 2026 |

Три первые ветки выросли одна из другой, поэтому в каждой лежат файлы
соседних: опрос и отчёт по безопасности есть во всех трёх, мониторинг —
только в своей. Смотреть нужно ту папку, ради которой ветка заведена.

## Как добавить задачу

Новая ветка от этой, имя `claude/<про-что>-<суффикс>`, строка в таблицу выше.
Ветки друг в друга не вливаются: их незачем сводить в одно дерево.
