# Дом мечты

Веб-приложение для телефона: спроектируй дом снаружи и обставь комнаты внутри.
Рассчитано на подростков до ~15 лет — интерфейс и графика ближе к настоящему
редактору интерьеров, чем к детской игре. Работает в браузере, без установки.

## Что можно делать

**Снаружи** — 4 архитектурных стиля (скандинавский, современный, двухэтажный,
A-frame), материалы фасада (штукатурка, вертикальное дерево, кирпич, камень),
кровля (фальц, черепица, гонт, зелёная), цвет двери и рам, участок: газон,
дорожка, деревья, кусты, цветы, забор, садовые фонари.
Переключатель времени суток — день / закат / ночь, ночью светятся окна и фонари.

**Внутри** — три комнаты (гостиная, своя комната, кухня). Отделка стен
(краска, кирпич, рейки, бетон) и пола (дуб, орех, ёлочка, бетон, мрамор,
шахматная плитка, ковролин). Мебель добавляется тапом, двигается пальцем,
масштабируется, отражается и дублируется. Режим «вечер» приглушает свет
и зажигает лампы, гирлянду, экраны.

**Сохранение** — проекты хранятся в браузере (localStorage), можно вести
несколько домов параллельно.

## Как это устроено

Никакой сборки и внешних зависимостей — HTML, CSS и обычный JavaScript.

- **Вся графика — SVG, нарисованный в сантиметрах.** Диван шириной 224 см и
  холодильник высотой 188 см соотносятся друг с другом так же, как в жизни.
- **Комната строится в одноточечной перспективе.** Пол — трапеция со швами,
  сходящимися к точке схода; предмет, поставленный дальше, действительно
  меньше и уходит за ближние. Позиция хранится как `(x в см, глубина 0..1)`,
  масштаб и порядок отрисовки выводятся из глубины.
- **Материалы — процедурные.** Кладка, доска, ёлочка и плитка генерируются
  кодом с учётом перспективы, а не подставляются картинками.
- Тёмная тема поддержана на уровне токенов: системная, явно светлая и явно
  тёмная — три разных состояния.

## Структура

```
index.html              разметка экранов
css/style.css           дизайн-система, светлая и тёмная темы
js/assets.js            библиотека SVG: материалы, мебель, дома, зелень
js/app.js               геометрия перспективы, рендер, состояние, ввод
tools/build-preview.js  сборка всего в один самодостаточный HTML
```

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Собрать одностраничную версию:

```bash
node tools/build-preview.js dist/preview.html
```

## Что можно добавить дальше

- Больше комнат (ванная, прихожая) и предметов.
- Свободный поворот предметов, а не только отражение.
- `manifest.json` и иконки, чтобы ставить на домашний экран как приложение.
- Экспорт проекта в картинку, чтобы поделиться.
