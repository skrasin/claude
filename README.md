# 🏡 Мой дом мечты

Детская веб-игра для телефона: придумай и построй свой дом — снаружи и внутри.
Рассчитана на детей 6–9 лет, работает прямо в мобильном браузере, без установки.

## Что можно делать

- **Снаружи**: выбрать форму дома (одноэтажный / двухэтажный / широкий), покрасить
  стены, крышу, дверь и окна, оформить двор — трава, деревья, цветы, забор, дорожка.
- **Внутри**: обставить три комнаты (гостиная, спальня, кухня) — выбрать обои и пол,
  расставить мебель перетаскиванием пальцем, менять размер и отражать предметы.
- **Сохранение**: дом автоматически сохраняется в браузере (localStorage) и
  доступен при следующем открытии игры. Можно создать несколько домов.

## Технологии

Никакой сборки и зависимостей — чистые HTML, CSS и JavaScript.
Графика дома — инлайновый SVG (перекрашивается на лету через CSS-переменные),
мебель и декор двора — эмодзи.

## Как запустить

Открыть `index.html` в браузере, либо поднять локальный сервер (нужен из-за
подключения Google Fonts и для комфортной разработки):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000 на телефоне или в DevTools в режиме мобильного устройства
```

## Структура проекта

```
index.html      — разметка всех экранов
css/style.css   — стили, адаптированные под телефон
js/app.js       — вся логика игры (состояние, рендер, сохранение)
```

## Возможные следующие шаги

- Добавить иконку и `manifest.json`, чтобы игру можно было «установить» на
  домашний экран телефона (PWA).
- Больше комнат и вариантов мебели.
- Озвучка/анимации при выполнении действий.
