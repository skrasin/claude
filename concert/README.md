# Бюджет концерта

Файл: **`Бюджет_концерта.xlsx`** — один лист, одна таблица.

Строки и суммы. Жёлтые ячейки заполняете вы, остальное считается само.

```
БИЛЕТЫ                     кол-во × цена
1. ВАЛОВОЙ СБОР

2. Налоги УСН                       6%
3. Комиссия за продажу билетов      5%
4. Отчисления в РАО                 8%
5. ТЕХНИЧЕСКИЕ РАСХОДЫ     построчно, аренда звука и обеспечение площадки
6. ПРИБЫЛЬ

   Доля площадки                   50%
   ПРИБЫЛЬ ОРГАНИЗАТОРА

   Налоги                           7%
   Банковские комиссии              1%
   ГОНОРАРЫ АРТИСТАМ       построчно
   МАРКЕТИНГ И PR          построчно
   ПРОЧИЕ РАСХОДЫ          построчно + резерв

   ЧИСТЫЙ ДОХОД ОРГАНИЗАТОРА

СПРАВОЧНО: сколько нужно собрать и продать, чтобы выйти в ноль
```

## Проверка

Пересчитано в LibreOffice Calc: **67 формул, 0 ошибок**. Цифры сверены с
независимым расчётом на Python.
