# Финансовая модель концерта

Файл: **`Бюджет_концерта.xlsx`**

Модель клубного концерта (150–400 мест) со сделкой «раздел прибыли 50/50 с площадкой».
Все расчётные ячейки — живые формулы Excel: меняете вводные, весь файл пересчитывается.

## Схема расчёта

```
Валовой сбор (box office)
  − комиссия билетного оператора        (если удерживается из цены)
  − отчисления в РАО                     5% от валового сбора
  − УСН 6%                               УРОВЕНЬ 1 — только УСН
= Сбор после вычетов
  − постоянные расходы (смета)
  − переменные расходы на гостей
  + доп. доходы, участвующие в разделе
= ПРИБЫЛЬ К РАЗДЕЛУ
  → 50% площадке / 50% организатору
  − 6% + 1% + 1% = 8% с выплаты          УРОВЕНЬ 2 — УСН + взносы + банк
= Чистый доход от билетов
  + доп. доходы вне раздела за вычетом 8%
= ИТОГО ЧИСТЫЙ ДОХОД ОРГАНИЗАТОРА
```

## Листы

| Лист | Что внутри |
|---|---|
| **Дашборд** | Главные цифры на одном экране, вердикт по проекту, сравнение сценариев, чек-лист «что уточнить» |
| **Вводные** | Все параметры: зал, налоги, РАО, комиссии, условия раздела прибыли, резерв |
| **Билеты** | Матрица категорий (цена × квота × процент продажи) и блок дополнительных доходов |
| **Маркетинг** | Бюджет по каналам с воронкой охват → отклик → покупка, CPA по каждому каналу и проверка здоровья бюджета |
| **Расходы** | Смета с колонкой «Оплачивает»: строки площадки видны по рыночной цене, но в ваши расходы не попадают |
| **Экономика** | Полный водопад от кассы до денег в кармане, точка безубыточности, запас прочности |
| **Сценарии** | Пессимистичный / базовый / оптимистичный / аншлаг / точка безубыточности |
| **Чувствительность** | Матрица «цена × заполняемость» с цветовой заливкой и точка безубыточности при каждой цене |
| **Варианты** | 19 конкретных способов улучшить экономику, каждый привязан к ячейке модели |

## Соглашения по цвету

- **Синий шрифт на жёлтом фоне** — вводные, их можно менять
- **Чёрный** — формулы, менять не нужно
- **Зелёный** — ссылка на другой лист
