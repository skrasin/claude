# Финансовая модель концерта

Файл: **`Бюджет_концерта.xlsx`**

Все расчётные ячейки — живые формулы Excel: меняете вводные, весь файл пересчитывается.

## Схема расчёта

```
ЭТАП 1 — до раздела прибыли
  1. Валовой сбор
  2. − Налоги УСН 6%                    (с валового сбора)
  3. − Отчисления в РАО 8%              (с валового сбора)
  4. − Технические расходы              (аренда звука и обеспечение площадки)
  5. = ПРИБЫЛЬ

РАЗДЕЛ
     Прибыль делится пополам → половина = ПРИБЫЛЬ ОРГАНИЗАТОРА

ЭТАП 2 — из прибыли организатора
     − Налоги 7%
     − Банковские комиссии 1%
     − Гонорары артистам
     − Маркетинг и PR
     − Прочие расходы
  = ЧИСТЫЙ ДОХОД ОРГАНИЗАТОРА
```

Каждая статья расходов показана в водопаде **отдельной строкой** — расшифровка
идёт в столбце «Расшифровка, ₽» под соответствующим итогом и сворачивается
группировкой строк.

## Листы

| Лист | Что внутри |
|---|---|
| **Дашборд** | Главные цифры по обоим этапам, вердикт, сценарии, чек-лист «что уточнить» |
| **Вводные** | Ставки обоих этапов, условия раздела, переключатели «вычитать до раздела» |
| **Билеты** | Матрица категорий (цена × квота × процент продажи) → валовой сбор |
| **Технические** | Смета этапа 1: аренда звука, свет, персонал площадки |
| **Гонорары** | Гонорары по каждому участнику |
| **Маркетинг** | Бюджет по каналам с воронкой охват → отклик → покупка и CPA |
| **Прочие** | Прочие расходы плюс резерв на непредвиденное |
| **Экономика** | Полный водопад со всеми статьями, точка безубыточности |
| **Сценарии** | Пессимистичный / базовый / оптимистичный / аншлаг / безубыточность |
| **Чувствительность** | Две матрицы «цена × заполняемость»: прибыль до раздела и чистый доход |
| **Варианты** | 16 способов улучшить экономику, отсортированы по силе влияния |

## Ключевой переключатель

На листе «Вводные», раздел 7 — вычитать ли гонорары, маркетинг и прочие расходы
**до** раздела прибыли. По умолчанию «Нет» (ваша схема). Эффект на базовых цифрах:

| Что вычитается до раздела | Чистый доход организатора | Точка безубыточности |
|---|---:|---:|
| Ничего (текущая схема) | −72 131 ₽ | 268 билетов, 94% зала |
| Гонорары и маркетинг | −13 271 ₽ | 206 билетов, 72% зала |
| Гонорары, маркетинг и прочие | +28 012 ₽ | 163 билета, 57% зала |

## Соглашения по цвету

- **Синий шрифт на жёлтом фоне** — вводные, их можно менять
- **Чёрный** — формулы
- **Зелёный** — ссылка на другой лист
- **Серый курсив** — расшифровка статьи, подтягивается с детального листа

## Проверка

Пересчитано в LibreOffice Calc: **503 формулы, 0 ошибок**. Водопад базового
сценария и все три положения переключателей сверены с независимым расчётом на
Python — расхождений нет.

## Пересборка

```bash
pip install openpyxl
python3 build_model.py
python3 <путь к скиллу xlsx>/scripts/recalc.py Бюджет_концерта.xlsx 300
```

> Для пересчёта в среде должен быть установлен `libreoffice-calc`
> (одного `libreoffice-core` недостаточно — Calc не загрузит xlsx).
