# Бюджет концерта

Файл: **`Бюджет_концерта.xlsx`** — один лист, одна таблица на 15 строк.

```
1. ВАЛОВОЙ СБОР              кол-во × цена билета
2. Налоги УСН                              6%   } проценты
   Комиссия за продажу билетов             5%   } от валового
   Отчисления в РАО                        8%   } сбора
3. Технические расходы       одна общая сумма
4. ПРИБЫЛЬ
5. Доля площадки                          50%
6. ПРИБЫЛЬ ОРГАНИЗАТОРА
   Налоги                                  7%   } проценты от
   Банковские комиссии                     1%   } прибыли организатора
   Гонорары
   Маркетинг
   PR
   Прочие расходы
7. ЧИСТЫЙ ДОХОД ОРГАНИЗАТОРА
```

Жёлтые ячейки заполняете вы, остальное считается само.

Пересчитано в LibreOffice Calc: 10 формул, 0 ошибок. Итоги сверены
с независимым расчётом.
