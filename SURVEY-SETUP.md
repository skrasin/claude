# Опрос «Как прошёл массаж» — настройка

Опрос — это две статические страницы в папке `docs/`, которые можно раздавать через
GitHub Pages. Ответы складываются в Google-таблицу через веб-приложение Apps Script.

- `docs/index.html` — сам опрос, эту ссылку отправляют клиенту;
- `docs/results.html` — статистика, эта ссылка только для вас;
- `docs/assets/config.js` — единственный файл, который нужно заполнить руками;
- `apps-script.gs` — код для Google-таблицы.

## 1. Код в таблицу (3 минуты)

Таблица для ответов уже создана: **«Массаж — ответы опроса»** в вашем Google Диске.

1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите содержимое `Code.gs` и вставьте туда весь `apps-script.gs` из этого репозитория.
3. В строке `var RESULTS_KEY = '...'` впишите любое своё слово. Это пароль
   к странице результатов — его нужно будет ввести один раз в браузере.
4. Сохраните (значок дискеты).

## 2. Публикация веб-приложения

1. В редакторе Apps Script нажмите **Начать развёртывание → Новое развёртывание**.
2. Тип развёртывания — шестерёнка → **Веб-приложение**.
3. Настройки:
   - **Запуск от имени:** «Я» (ваш аккаунт);
   - **У кого есть доступ:** **«Все»** — иначе браузер клиента не сможет отправить ответ.
4. Нажмите **Развернуть**, разрешите доступ к таблице (Google покажет экран
   «Приложение не проверено» → «Дополнительные настройки» → «Перейти…» → «Разрешить»).
5. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.

> Если позже правите `apps-script.gs`, делайте **Управление развёртываниями → Изменить →
> Версия: Новая → Развернуть**, иначе на сервере останется старый код. Адрес при этом не меняется.

## 3. Адрес в конфиг

В файле `docs/assets/config.js` вставьте скопированный адрес:

```js
window.SURVEY_CONFIG = {
  endpoint: "https://script.google.com/macros/s/AKfycb.../exec"
};
```

Закоммитьте и запушьте изменение.

## 4. GitHub Pages

Settings → Pages → **Source: Deploy from a branch** → ветка с этим кодом,
папка **`/docs`** → Save. Через минуту страницы будут доступны:

- опрос: `https://skrasin.github.io/claude/`
- результаты: `https://skrasin.github.io/claude/results.html`

Клиенту отправляют первую ссылку. Вторую храните для себя: при первом открытии она
спросит слово из `RESULTS_KEY` и запомнит его в браузере.

## Что где хранится

Ответы лежат только в вашей Google-таблице: дата, оценка 1–5, оценка 0–10,
технический идентификатор отправки и комментарий. Ни имён, ни адресов, ни
куки-трекинга.

Поле для комментария («Подскажите, пожалуйста, что мы могли бы улучшить?»)
показывается только тем, кто поставил не 5 в первом вопросе или не 10 во
втором; заполнять его необязательно. Колонку «Комментарий» скрипт дописывает
в таблицу сам при первом таком ответе.
Страница результатов ничего не хранит — она каждый раз читает таблицу заново.
